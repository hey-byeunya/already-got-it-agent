**모의 오류로 확인한 항목**과 **실제 엔진으로 확인한 항목**을 구분한다.

- 앱 버전 · 커밋: CHECKLIST V1~V5 확인 당시 — 이후 변경은 `git log`로 대조한다

## 4절이 지정한 5가지 상황

### V1. 독자 질문이 나온 뒤 새로고침

| 칸 | 내용 |
|---|---|
| 입력·조작 | 살아 있는 실행(`web-mtu1tqmf`)에서 페이지를 다시 열었다 |
| 기대 결과 | 같은 프로젝트의 질문과 선택지가 남고, 답변 전에는 제작이 시작되지 않는다 |
| 실제 결과 | 저장된 상태가 그대로 그려졌다. 수정 없음 |
| 수정 후 결과 | — (첫 확인에 통과) |

- 확인 방식: ☑ 실제 엔진 ☐ 모의 오류
- 증거: 실행 기록 `runs/web-mtu1tqmf` (gitignore라 로컬에만). 화면 캡처는 `RUN.md` 캡처 목록 3-③으로 이관
